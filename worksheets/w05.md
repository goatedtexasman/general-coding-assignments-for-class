## Part 6 Case A, B, C

Find the Error

Case A:

[class Car : Vehicle] with no keyword defaults to **private** inheritance (mirrors W01: no label = private). That turns every inherited **public** member of **Vehicle**, including **describe()**, into a **private** member of **Car**. Line X ([c.describe();] in **main()**) does ***NOT compile*** - **describe** is private within this context. Fix: [class Car : public Vehicle]. 

Case B: 

Does ***NOT compile***. [Car(int doors)] never chains to a **Vehicle** constructor, so the compiler tries to call supply **mk**. Fix: give **Car** a **string** parameter too and chain it -- **Car(string mk, int doors) : Vehicle(mk), numDoors(doors) {}**.

Case C:

Does ***NOT compile***. **protected** only widens access for derived classes - it does nothing for outside code. **main()** is not a member of **Vehicle** or any class derived from it, so **v.make** is just as unreachable as if **make** were **private**.
